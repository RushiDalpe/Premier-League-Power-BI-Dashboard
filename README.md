# Premier League Performance Intelligence Dashboard

## Project Overview

This project analyses Premier League performance data across 26 gameweeks and 20 teams. The interactive Power BI dashboard was developed to compare team performance writers, monitor key indicators and identify patterns across the season.

## Business Objective

The objective was to transform raw weekly football data into a clear and interactive reporting solution that allows users to:

- Compare team performance across different gameweeks
- Identify league leaders and underperforming teams
- Monitor points, wins, losses and goal difference
- Explore changes in performance using interactive filters
- Present complex data in an accessible visual format

## Tools and Technologies

- Power BI
- Power Query
- DAX
- Python
- pandas
- Jupyter Notebook
- CSV data sources

## Data Preparation

Fourteen CSV files containing weekly league information were consolidated into one structured dataset. The data-cleaning process included:

- Combining multiple gameweek files
- Standardising team names and column formats
- Checking for missing and duplicate records
- Correcting data types
- Validating points and goal-d-difference values
- Creating a gameweek field for trend analysis

The final dataset contained 280 records and 11 columns.

## Dashboard Features

- League leader indicator
- Selected-team performance cards
- Total points by team
- Goals scored and goals conceded
- Goal-difference analysis
- Team-performance comparison
- Gameweek and team slicers
- Detailed league table
- Interactive cross-filtering between visuals
